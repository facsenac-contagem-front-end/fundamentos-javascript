O que é JavaScript

JavaScript é a linguagem de programação da web. Se o HTML é o esqueleto da página e o CSS é a roupa, o JavaScript é o movimento: ele faz a página reagir ao que a pessoa faz.

HTML
Estrutura
títulos, textos, botões
CSS
Estilo
cores, fontes, layout
JS
Comportamento
cliques, validações, dados

Criada em 1995 por Brendan Eich, na Netscape. O padrão oficial se chama ECMAScript. E JavaScript não tem nada a ver com Java.

Console do navegador

Todo navegador tem um console escondido. Ele roda JavaScript na hora e mostra as mensagens de erro da página.

1Abra qualquer página
2Aperte F12
3Abra a aba Console
4Digite e aperte Enter

Atalho direto no Chrome: Ctrl + Shift + J no Windows ou Cmd + Option + J no Mac.

Caixas com etiqueta

Uma variável guarda um valor para usar depois. O nome é a etiqueta; o valor é o que está dentro da caixa.

const
Valor fixo
Não pode receber outro valor. Use por padrão.
let
Valor que muda
Contadores, totais, respostas do usuário.
var
Forma antiga
Aparece em código velho. Evite em código novo.

Arrays: listas em ordem

Um array guarda vários valores em ordem. Cada posição tem um número, o índice, que começa em 0. Clique numa caixa para ler o valor.

Objetos: fichas com nome e valor

Um objeto agrupa informações sobre a mesma coisa. Cada informação tem uma chave (o nome) e um valor. Use array quando a ordem importa; use objeto quando cada valor tem um nome.
